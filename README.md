# Portfólio — Matheus Merlim

Site de portfólio pessoal com links para todos os projetos no GitHub.

## Como subir no GitHub Pages

1. Crie um repositório no GitHub chamado `matheusmerlim1.github.io`
2. Faça upload do arquivo `index.html`
3. Vá em **Settings → Pages → Source → Deploy from branch → main**
4. Acesse: `https://matheusmerlim1.github.io`
